================================================================================
WHAT THIS APP IS
================================================================================

Cosmic Intentions — a personal goals and visualization web app.
- Users set intentions/goals, then engage with them through timed players
  (meditation, countdown, visualization, gratitude, video)
- Pure client-side. No build step. No bundler. Vanilla HTML/CSS/JS on Netlify.

ARCHITECTURE NOTES
================================================================================

- No server-side code. Netlify is static hosting only. All logic is client-side JS.
- Supabase handles auth and postgres. Check existing schema before suggesting new tables.
- Google Sheets is a data source — accessed via API or Apps Script, not a DB replacement.
- Daily rotating images per player use PLAYER_OFFSETS — already solved, do not re-implement.
- launchVisualCountdown() passes goal text + duration via localStorage to visual-countdown player.
- Env var changes in Netlify require a redeploy (push to main) to take effect.
- Netlify function timeout is a real constraint — Mission Control generates 50 items per call
  and appends on next generation to avoid timeout.
