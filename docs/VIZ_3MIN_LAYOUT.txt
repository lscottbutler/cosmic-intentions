===================== 4. TIMELINE — 7-BLOCK STATE MACHINE =====================
   total = 180s   CORE = total-56 = 124s   STEP scrub = 10s
   (deepen/embody scale with CORE, so 10-min just stretches this middle band)

   PHASE 1: HOOK          PHASE 2: DESCENT/LUNGS      PHASE 3: CORE (x3)     PH4
   |                      |                           |                      |
   v                      v                           v                      v
   0s    8s         20s   34s          76s           118s             158s   180s
   |-----|-----------|-----|------------|--------------|----------------|-----|
   B1    B2          B3    B4           B5             B6               B7   END
   HOOK  DESCENT    LUNGS  CORE·ENTER   CORE·DEEPEN    CORE·EMBODY      EXIT  bell
   @0    @8         @20    @34          @76            @118            @158   +4s
                           ^^^^ speaks the user's GOAL via runtime /api/tts
   ||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||
   formulae:  B5 = 34 + round(CORE*0.34) = 76     B6 = 34 + round(CORE*0.68) = 118
              B7 = total - 22 = 158               END = total = 180 -> bell, close

============================= 7. AUDIO ARCHITECTURE =========================
   |||  static cues (6)  ............  preloaded <audio>, played at block time
   |||  goal cue (B4)  ..............  fetch /api/tts {text, voice:'shimmer'}
   |||                                 -> data:audio/mpeg base64 -> <audio>
   |||  end bell  ...................  WebAudio 2-tone sine on session end
   |||  autoplay unlock  ............  first pointerdown primes all clips (muted play)


============================== 8. LIFECYCLE / FLOW ==========================
   load -> read inputs -> paint label + image -> preload static cues
        -> kick off B4 runtime TTS (ready well before @34)
   +0.8s  auto-start: setPlaying(true), fire B1 HOOK
   every 1s  tick(): elapsed++, move dot, fire any block whose .at <= elapsed
   @180s  endSession(): stop, play bell, setTimeout(finishPlayer, 4000)
          finishPlayer -> parent.playerFinished() (advance favorites) or close
   ============================================================================
   DEV_MODE = true -> on-screen caption of each block (verify without audio)
              (note: app DEV_MODE is hostname-based; this player flag is its own)
