# Independent narration placement

Adds two drag/keyboard handles to each gold narration block. Either handle moves the full recorded passage, preserving source duration and words. Positions are saved as voiceStarts, with ordered non-overlapping limits. Grey gaps and approximate clip timestamps update independently from blue slide timing. Opening delay offsets all narration placements. Preview uses elapsed session time and maps each active passage into its original position within existing full recording; audio pauses in gaps and closing bell stays in final five seconds. No audio regeneration or destructive trimming. Changes remain editor-preview-only, with text/voice mismatch possible when manually moving passages relative to slides.
