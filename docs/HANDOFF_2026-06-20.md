## What we've been building (this stretch)
The **Meditation player** and how it launches from the dashboard. It went through
several pivots — here's where it landed, not the dead ends.

### The player — `players/meditation.html` (~207 lines, self-contained)
A standalone page opened with `?t=<minutes>` (e.g. `?t=15`). Current design:

- **Shape:** a portrait-ish card. Gray frame border (`--frame-gray #8b8b8b`),
  `--frame-ratio: 5 / 6`.
- **Top ~56%:** the background image, `background-size: contain` (whole image
  always shows, never cropped; letterboxed on a white backdrop).
- **Bottom panel:** **white** background, **black** text (just changed from a
  dark indigo theme). Contains:
  - label: `"{t} minute unguided meditation"`
  - centre **badge** (white fill, gray ring, black text): shows `{t} / MIN`,
    then counts down `m:ss` to a synthesized **Web-Audio bell** at 0:00.
  - **◀ ▶ arrows = rewind / forward the TIMER** (±60s, clamped 0..total) — NOT
    image navigation.
  - **H button = home** → calls `window.parent.closePlayerColumn()` when embedded
    in the dashboard, else `history.back()` / `window.close()`.
- **Bell:** generated in JS via `AudioContext` (two sine tones). There is NO
  bell.mp3 in the repo — do not reference one.

### Background images — `images/meditation/`
- Files: `meditation.jpg`, `meditation-1.jpg`, `meditation-2.jpg`,
  `meditation-3.jpg`. One shown per day, rotating (`getDate() % IMAGES.length`).
- To add more: drop the file in `images/meditation/` AND add its filename to the
  `IMAGES` array in `players/meditation.html`.
- Only `images/` is copied into the deploy (`vite.config` static-copy). A folder
  anywhere else (e.g. repo-root `meditation/`) will NOT go live.
- ⚠️ The images are mixed ratios (3:2 and 2:1), which is why `contain` (with white
  letterbox bars) is used instead of `cover`. If they're standardized to one
  ratio, switch the photo area to that ratio + `cover` for an edge-to-edge fill.
- ⚠️ `meditation-1.jpg` is **7.6 MB** — far too big for a web background and it
  bloats the repo / Netlify quota. Needs compressing to ~300–500 KB. No image
  compressor exists in this environment (no sharp/ImageMagick) — compress it
  externally (Photoshop "Save for Web" / online tool) and replace.

### How it launches from the dashboard — `index.html` + `shared/player-launcher.js`
- In the dashboard **Column B (the sidebar, `#vaultSidebar`)** there's a
  **MEDITATION TIMERS** dropdown (banner + 9 time buttons: 1/3/5/10/15/20/30/45/60).
- Directly **above** that dropdown sits `#playerColumn` — a hidden panel with a
  **← Back** button + an `<iframe id="playerColumnFrame">` (aspect-ratio 5/6).
- `openPlayerInColumn(src)` shows that panel and loads the player in the iframe,
  in place (nothing else hidden). `closePlayerColumn()` hides it + unloads the
  iframe (stops audio/timer). Both are exported from `shared/player-launcher.js`
  and wired onto `window` via the HANDLERS list in `src/main.js`.
- NOTE: an earlier "Column Takeover" (hide the whole column) was built then
  **reverted** — do not reintroduce it. The player just opens above the dropdown.
