# Affirmation Sets — master list

This is the ONE place you list affirmations. Tell me "build the credit-score one"
(or "rebuild all") and I'll pull from here and generate the matching page in player/.

## How to add a set
- Start a new block with `## <short-name>`  (this becomes the file: <short-name>.html)
- `art:`   path to your square artwork (relative to player/, so root images = ../images/...)
- `title:` optional — page tab title
- Then one affirmation per line, each starting with `- `
- Optional per-set tuning: `slideMs:`, `fadeMs:`, `fit:`, `pos:`
