# Cosmic Intentions — outside-tool design exploration brief
Status: CONCEPT EXPLORATION ONLY. Prepared 21 October 2026 for Scott.

## Objective
Explore 20 clearly different visual concepts, organized as five directions with four variations each. Show the SAME content on Citadel, Goals, and the surrounding Meditation player page in each concept. Do not replace or deploy the existing product.

## Existing product
Cosmic Intentions / The Inner Citadel helps members set goals, plan practical actions, visualize, meditate, reflect, and practise gratitude. The current source is a private Vite/Netlify project. Avoid framework migration. Preserve the existing Supabase interface; no connection is needed for these studies.

## Content used consistently
Citadel: “Make room for what matters.” Daily invitation: ten minutes to settle and begin again. Practices: Meditation, Super Viz, Gratitude. Goal: “Build a calmer daily routine.” Next action: set aside ten minutes this evening.
Goals: calmer routine; personal film project; make room for learning. Opening a goal offers Visualization and Roadmap.
Player: use the approved Meditation master as a fixed reference; vary only the surrounding page.

## Five directions
1. Quiet Sanctuary: calm, spacious, minimal stimulation.
2. Intentional Editorial: strong typography, journal quality, precise hierarchy.
3. Modern Citadel: architectural, goal-focused command centre.
4. Living Garden: grounded, warm, organic structure.
5. Focus Studio: clear, efficient, functional.

Within each direction vary layout and navigation as well as palette. Avoid 20 near-identical templates. Every concept needs desktop and phone treatment and a numbered name. Preserve content meaning and actual product capabilities. No invented testimonials, outcomes, member counts or scarcity. Pricing, if used: $9.99 monthly / $79 yearly, 14-day trial; CTA “MAP MY GOAL”.
