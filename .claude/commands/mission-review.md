# COSMIC INTENTIONS — Mission Control & Roadmap Quality Filter

When this skill is invoked, apply ALL of the following rules and standards
to any AI-generated Mission Control items, Roadmap items, or AI Library
content before it is shown to the user. This is the master filter.

---

## WHAT COSMIC INTENTIONS IS

Cosmic Intentions is a personal development web app. It is the user's
Personal Operating System for Life Design. The app already provides:
- Goal setting (intentions are already defined when users arrive here)
- Visualization players (3-min, 10-min, visual countdown)
- Meditation players (guided, unguided)
- Gratitude practice
- Vision board / goal images
- Pegboard (mission, values, beliefs, core identity)
- Night Protocol
- AI Roadmap
- AI Library (affirmations, mindset, achievers)
- Mission Control (100-item research roadmap with YES/DEEPER flagging)
- Daily Commitments tracker with streak counting

**The app already does all of the above. Never generate content that tells
the user to do something the app already provides.**

## THE PEGBOARD — USER'S CORE IDENTITY DATA

The Pegboard is the foundation. Every piece of generated content should
be filtered through it. Pull from these fields when available:

- **pb-name** — user's name
- **pb-mission** — their life mission statement
- **pb-lifegol** — their life goal
- **pb-values** — their core values
- **pb-beliefs** — their core beliefs
- **pb-attitudes** — their mental attitudes
- **pb-stoicism** — their stoic principles
- **pb-traits** — their character traits
- **bts-tone** — their preferred tone/voice
- **bts-authors** — authors/thinkers they resonate with
- **bts-obstacles** — their known obstacles
- **bts-why** — their deep why
- **bts-context** — additional context about who they are

**If Pegboard data is available, EVERY generated item must be filtered
through it. A person whose mission is spiritual growth gets different
advice than someone whose mission is building a billion-dollar company.
Same frameworks, completely different application.**

## HARD RULES — APPLY TO EVERY GENERATED ITEM

These are non-negotiable. Any item that violates a rule is rejected
and regenerated.

1. **NO GOAL SETTING** — The user has already set their goal. Never tell
   them to write it down, define it, get clear on it, or create a
   goal statement. It is done.

2. **NO VISION BOARDS** — The app already creates vision boards with
   AI-generated images. Never suggest creating one.

3. **NO MEDITATION / GRATITUDE / JOURNALING as a primary action** — The
   app has dedicated players for all of these. Suggesting them is
   redundant.

4. **NO GENERIC ADVICE** — "Stay motivated", "believe in yourself",
   "be consistent" are banned. Every item must be SPECIFIC to the
   exact goal and the exact person.

5. **NO ACADEMIC CITATIONS** — Never cite Bandura, 1997 or any unknown
   researcher. Use famous people everyone has heard of.

6. **NO REPEATED IDEAS** — Each item in a set must be completely distinct.
   No variations of the same concept.

7. **NO PLANNING PHASE ADVICE** — The user is past planning. They want
   EXECUTION. What to do, how to think, what obstacles to destroy.

8. **NO OBVIOUS ADVICE** — If a 10-year-old could have said it, cut it.

## THE QUOTE STANDARD

Every "why" field must cite 2 famous people using the STORY behind
the quote, not the headline everyone knows.

**WRONG:** "Jim Carrey wrote himself a $10M check."
**RIGHT:** "Jim Carrey drove to Mulholland Drive every night with nothing
in his pocket and sat there FEELING the success as real — he said
'visualization works if you work hard. That's the thing.'"

**WRONG:** "Kobe worked hard."
**RIGHT:** "Kobe arrived at 4am, took 800 shots before anyone else showed
up — the edge is always in the hours nobody sees."

**Use 2 bullet points per card, separated by |**

Famous people to draw from (everyone knows these names):
Ali, Kobe, Jordan, Carrey, Robbins, Oprah, Jobs, Bezos, Musk, Goggins,
Buffett, Hill, Mandela, Carnegie, Lincoln, Tyson, Schwarzenegger,
Federer, Dalio, Hormozi, Naval, Sinek, Frankl

## THE THOUGHT LEADER FRAMEWORKS

Apply the most relevant framework(s) to each item:

- **James Clear (Atomic Habits):** identity-based habits, habit stacking,
  1% improvement, two-minute rule, environment design
- **Simon Sinek (Start With Why):** purpose drives behavior, why before what
- **Stephen Covey (7 Habits):** begin with end in mind, sharpen the saw,
  proactive vs reactive, circle of influence
- **Napoleon Hill (Think and Grow Rich):** definite chief aim, mastermind
  groups, burning desire, auto-suggestion
- **Tony Robbins:** state management, power of decision, RPM planning,
  the six human needs
- **Carol Dweck (Growth Mindset):** fixed vs growth identity, power of yet
- **Cal Newport (Deep Work):** eliminate shallow work, deep focus blocks,
  attention residue, craftsman mindset
- **Rory Sutherland (Alchemy / Sutherland Lens):** The psychologically
  effective answer is rarely the logical one. Reframe the problem.
  Design for perception not just reality. What signals are you
  sending yourself? Apply this lens to 2-3 items per set minimum.
- **BJ Fogg (Tiny Habits):** make it tiny, anchor to existing habits,
  celebrate small wins immediately
- **Viktor Frankl:** meaning in the struggle, purpose creates endurance
- **Robert Cialdini (Influence):** social proof, commitment and consistency,
  identity-based compliance
- **Naval Ravikant:** specific knowledge, long-term thinking, play games
  where you have unique advantage, earn with your mind not time
- **Alex Hormozi:** speed of implementation, grand slam focus, make the
  obvious move obvious
- **Ray Dalio (Principles):** pain + reflection = progress, radical
  transparency, write down every mistake and the rule to prevent it
- **David Goggins:** callusing the mind, accountability mirror, 40% rule
  (when you think you're done you're 40% there)

## THE FOUNDATION CARD (always present)

Every Mission Control set opens with this permanent card:

**★ FOUNDATION — The 5 Things I Ask Myself When I F*ck Up**

- Nelson Mandela: "I never lose. I either win or I learn."
- Ray Dalio borrowed $4,000 from his dad after losing everything in 1982
  — wrote down every mistake and the rule to prevent it. That system
  became Bridgewater, the world's largest hedge fund.
  "Pain + Reflection = Progress. Every mistake you don't examine is
  a tax you pay twice."

**The 5 Questions:**
1. What exactly went wrong — be surgical, not emotional
2. Did I see the warning signs and ignore them?
3. What does this reveal about a blind spot in me?
4. What's the rule I'm creating so this never happens again?
5. Who do I need to become so this mistake is impossible?

## QUALITY CHECKLIST — RUN BEFORE APPROVING ANY GENERATED CONTENT

Before any content is shown to users, check:

[ ] Does it assume the goal is already set? (yes = good)
[ ] Is it specific to THIS goal and THIS person? (yes = good)
[ ] Does it avoid things the app already does? (yes = good)
[ ] Does each "why" cite 2 famous people with real stories? (yes = good)
[ ] Does it apply at least one named framework? (yes = good)
[ ] Is the Sutherland Lens applied somewhere in the set? (yes = good)
[ ] Is the advice executable, not theoretical? (yes = good)
[ ] Is the tone direct and premium, not fluffy? (yes = good)
[ ] Is the Pegboard data reflected where available? (yes = good)
[ ] Would a serious achiever find this genuinely useful? (yes = good)

If any answer is NO — regenerate that item.

## HOW TO USE THIS SKILL

When invoked with `/mission-review`, take the provided content
(Mission Control items, Roadmap items, or AI Library output) and:

1. Run each item through the Hard Rules above
2. Flag any violations
3. Rewrite flagged items to pass all rules
4. Confirm the Sutherland Lens is applied
5. Confirm 2-bullet quote format on every card
6. Return the cleaned, approved set

If Pegboard data is provided, personalize every item to match.
